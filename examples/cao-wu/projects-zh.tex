  \cventry
    {\textcolor{awesome-red}{毕业设计 / vLLM 开源贡献}}
    {Scheduling for Expert Movement in vLLM's EPLB}
    {米兰理工大学}
    {2026年5月 -- 2026年10月}
    {
      \begin{cvitems}
        \item {\textbf{项目概述：}针对异步 EPLB 专家迁移与在线推理争抢网络带宽、拉高服务延迟的问题，设计并实现 contention-aware 专家迁移批调度机制。\href{https://github.com/vllm-project/vllm/pull/52641}{vLLM PR \#52641} 已于 2026 年 10 月合入主分支，\textbf{\textcolor{awesome-red}{该优化已被 vLLM 合入，成为 vLLM 官方特性。}}}
        \item {\textbf{调度设计：}按源/目标 rank 组织迁移并拆分为无冲突批次，使每个 rank 在单批次内至多与一个对端通信，同时保留互不冲突 rank 对之间的并发传输，降低 rank 级通信热点与 NIC 瞬时拥塞。}
        \item {\textbf{工程集成：}将调度器集成至 vLLM 异步 EPLB/NIXL 迁移链路；在每次重平衡周期中一次性生成全部 48 个 MoE Layer 的调度计划，迁移仍按 Layer 执行，在控制网络竞争的同时降低 Python 调度开销，并保持同步 EPLB 原有路径不变。}
        \item {\textbf{性能收益：}在 4 节点、TP=4、32 并发的 Qwen3-30B-A3B 在线服务测试中，请求吞吐提升 \textbf{2.28\%}；TTFT P50/P99 降低 \textbf{1.18\%/1.30\%}，TPOT P50/P99 降低 \textbf{1.94\%/0.87\%}，E2EL P50/P99 降低 \textbf{3.18\%/1.50\%}；NIC 流量 P99 降低 \textbf{10.24\%}，调度总开销仅为节省服务时间的 \textbf{0.285\%}。}
      \end{cvitems}
    }
